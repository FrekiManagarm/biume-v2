# Biume Mobile

Expo SDK 57 application for Biume's mobile capture and synchronization client.
Generated with `create-expo-app --template default@sdk-57` and wired into the
Bun workspace at the repository root.

## Get started

From the repository root:

```bash
bun install
bun run dev:mobile
```

## Checks

```bash
bun run test:mobile
bun --filter @biume/mobile check-types
bun --cwd apps/mobile x expo install --check
```

## Native development builds

```bash
bun run ios:mobile
bun run android:mobile
```

The `ios/` and `android/` directories are generated by prebuild and are not
committed. Application identity, permissions, and plugins live in
`app.config.ts`; build profiles live in `eas.json`.
